📌 About This Repository

This repository contains my Machine Learning Laboratory Practicals completed as part of the academic curriculum.

The practicals are organized in a progressive way — starting with the Python environment and basic data visualization, and gradually moving towards machine learning algorithms and neural networks.

The main goal of this repository is not just to run the algorithms, but to understand how different machine learning techniques work, where they are used, and how their results can be analyzed using Python.

The practicals cover:

- 📊 Data visualization and exploratory analysis
- 📈 Linear Regression
- 🌳 Decision Tree
- 👥 K-Nearest Neighbors
- 🧮 Naive Bayes
- 🌲 Random Forest
- 🔵 K-Means Clustering
- 📐 Support Vector Machine
- 🧠 Single-Layer Perceptron

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/Ammara-cse/Machine-Learning-Lab-Practicals.git
cd Machine-Learning-Lab-Practicals

2. Install Required Libraries

pip install numpy pandas matplotlib seaborn scikit-learn jupyter

3. Start Jupyter Notebook

jupyter notebook

Open the required ".ipynb" file and run the cells step by step.
