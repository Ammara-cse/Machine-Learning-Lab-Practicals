It progresses systematically from environment configuration and exploratory data visualization to regression, classification, ensemble learning, clustering, and single-layer neural networks.

## 🚀 How to Run Locally

1. **Clone the repository:**
```bash
git clone [https://github.com/Ammara-cse/Machine-Learning-Lab-Practicals.git](https://github.com/Ammara-cse/Machine-Learning-Lab-Practicals.git)
cd Machine-Learning-Lab-Practicals

```


2. **Install required dependencies:**
```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter

```


3. **Launch Jupyter Notebook:**
```bash
jupyter notebook

```
