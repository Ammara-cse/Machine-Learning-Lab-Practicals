# Machine Learning Lab Practicals

This repository contains hands-on Machine Learning laboratory practicals implemented using **Python** and **Jupyter Notebook**. It covers environment setup, exploratory data visualization, supervised classification/regression models, unsupervised clustering, and neural network fundamentals.

## Lab Practicals Index

| Sr. No. | File Name | Topic / Algorithm Covered | Category |
| :--- | :--- | :--- | :--- |
| **01** | `01_Anaconda & Python Environment Setup.pdf` | Anaconda & Python Environment Setup Guide | Environment Setup |
| **02** | `02_graphs_and_charts.ipynb` | Data Visualization using Graphs & Charts | Exploratory Data Analysis |
| **03** | `03_Linear_Regression.ipynb` | Simple & Multiple Linear Regression | Supervised (Regression) |
| **04** | `04_Decision_Tree.ipynb` | Decision Tree Classifier | Supervised (Classification) |
| **05** | `05_KNN.ipynb` | K-Nearest Neighbors (KNN) | Supervised (Classification) |
| **06** | `06_Naive_Bayes.ipynb` | Naive Bayes Classifier | Supervised (Classification) |
| **07** | `07_Random_Forest.ipynb` | Random Forest Ensemble Model | Supervised (Classification) |
| **08** | `08_kmeans.ipynb` | K-Means Clustering | Unsupervised Learning |
| **09** | `09_svm.ipynb` | Support Vector Machine (SVM) | Supervised (Classification) |
| **10** | `10_perceptron.ipynb` | Single-Layer Perceptron | Neural Networks |

## Datasets Included
* **`Salary_Data.csv`** — Used for Salary prediction with Linear Regression.
* **`diabetes_prediction_dataset.csv`** — Used for classification and clustering experiments.
* **`diabetes_clustered_output.csv`** — Processed output dataset generated from clustering analysis.

## Tech Stack
* **Language:** Python 3
* **Environment:** Jupyter Notebook / Anaconda
* **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn
